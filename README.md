# چهارسو (Flutter، اندروید)

اپ مدیریت زمان با ماتریس آیزنهاور؛ راست‌به‌چپ، تقویم شمسی، ماتریس قابل کشیدن، گلیم هفته و زمان‌سنج تمرکز.

## ساخت فایل نصبی (APK)

### روش ۱: بدون نصب چیزی روی کامپیوتر (GitHub Actions)
1. یک مخزن (repository) خالی در GitHub بسازید.
2. همه‌ی فایل‌های این پوشه را (شامل پوشه‌ی پنهان `.github`) در مخزن آپلود کنید.
3. به تب **Actions** بروید، workflow با نام **Build Android APK** را اجرا کنید (Run workflow).
4. بعد از چند دقیقه، در پایین صفحه‌ی اجرا در بخش **Artifacts** فایل `chaharsu-apk` را دانلود کنید.
5. فایل `chaharsu.apk` را روی گوشی اندروید کپی و نصب کنید (باید «نصب از منابع ناشناس» را برای مرورگر یا فایل‌منیجر مجاز کنید).

### روش ۲: روی کامپیوتر خودتان
پیش‌نیاز: Flutter (کانال stable)، JDK 17 و Android SDK (با `flutter doctor` بررسی کنید).

```bash
bash tools/build_apk.sh
```
خروجی: `dist/chaharsu.apk` (در ویندوز از WSL یا Git Bash استفاده کنید).

## ساختار
- `lib/core.dart` مدل‌ها، وضعیت برنامه، ذخیره‌سازی، تاریخ شمسی، پالت رنگ
- `lib/painters.dart` نشان چهارگلبرگ، حلقه‌ها، الگوی ختایی، گلیم هفته
- `lib/today_screen.dart`، `matrix_screen.dart`، `focus_screen.dart`، `stats_screen.dart` صفحه‌ها
- `lib/task_sheet.dart` برگه‌ی افزودن و ویرایش کار
- `android_res/` آیکن برنامه؛ `tools/` اسکریپت‌های ساخت

## فونت‌ها
اسکریپت ساخت، فونت‌های وزیرمتن و لالزار را (مجوز SIL OFL) دانلود و به برنامه اضافه می‌کند.
اگر دانلود ممکن نبود، برنامه با فونت فارسی خود اندروید ساخته می‌شود.
